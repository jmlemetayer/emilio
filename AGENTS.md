# Agent instructions

The rules for this repository live in **[CONTRIBUTING.md](CONTRIBUTING.md)**. Read it before making
any change: it covers the project layout, how changes land, the commit convention, checks to run,
and the hard rules that will get a change rejected.

There is nothing agent-specific beyond that file. What is expected of you is what is expected of a
human contributor — you own what you submit, you understand it, and you only report results you
actually observed.
